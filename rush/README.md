# 🧟 LAST SHELTER — ศูนย์พักพิงสุดท้าย

**เกมเอาชีวิตรอดวันสิ้นโลกซอมบี้: บริหารคน เสบียง และการติดเชื้อ ให้รอดจนเฮลิคอปเตอร์มารับในวันที่ 15**

โลกถูกโรคระบาดกลืนกิน ผู้เล่นเป็นหัวหน้าศูนย์พักพิงแห่งสุดท้ายในเมือง วิทยุได้ยินว่า **เฮลิคอปเตอร์ช่วยเหลือจะมาถึงหลังวันที่ 15** ระหว่างนี้ต้องตัดสินใจทุกวัน
- ใครจะออกไปหาเสบียง ใครเฝ้ายาม ใครรักษาคนเจ็บ
- จะสร้างอะไรก่อน
- จะใช้ยาที่มีจำกัดรักษาใคร
- จะเปิดประตูให้คนแปลกหน้าที่อาจติดเชื้อมาแล้วหรือไม่

ซอมบี้มี **5 เลเวล** ยิ่งผ่านไปหลายวันยิ่งเจอชนิดที่อันตรายขึ้น ส่วนผู้รอดชีวิตแต่ละคนมี **พลังพิเศษ** ที่เก่งขึ้นได้ถึงเลเวล 5

เกมรองรับภาษาไทยและอังกฤษ และบันทึกความคืบหน้าลงไฟล์ JSON อัตโนมัติ

## 🚀 วิธีรัน

ต้องใช้ **Python 3.6 ขึ้นไป** และไม่ต้องติดตั้ง package เพิ่ม (ใช้แค่ standard library: `os`, `json`, `copy`, `random`, `time`)

```bash
cd rush
python3 main.py
```

```bash
python3 gui.py
```

### ในแต่ละวัน
1. **มอบหมายงาน** ให้ทุกคน (คนละ 1 งาน) หรือกด **จัดงานอัตโนมัติ**
   - 🎒 **ออกไปหาเสบียง:** ได้อาหาร น้ำ เศษวัสดุ แต่เสี่ยงโดนข่วนจนติดเชื้อ
   - 🛡 **เฝ้ายาม:** พลังป้องกัน = ทักษะต่อสู้ × 3 (+ โบนัสแม่นปืน)
   - ✚ **รักษา:** ใช้ยา 1 ชิ้น รักษาคนติดเชื้อก่อน ถ้าไม่มีใครติดเชื้อจะรักษาคนที่ HP ต่ำสุด
   - 💤 **พักผ่อน:** ฟื้น HP 15
2. **สร้างสิ่งก่อสร้าง** ด้วยเศษวัสดุ (อย่างละครั้ง): 🚧 แนวกั้นเหล็ก (ป้องกัน +6), 🥬 แปลงผัก (อาหาร +1/วัน), 🛢 ถังเก็บน้ำฝน (น้ำ +1/วัน), 🏥 ห้องปฐมพยาบาล (ยา +1 ทุก 2 วัน)
3. **ประตู:** คนแปลกหน้ามีพลังพิเศษติดตัวมา แต่อาจติดเชื้อ จะใช้คนว่าง 1 คนตรวจร่างกายก่อน หรือจะเสี่ยงรับเลยก็ได้
4. **จบวัน:** เกมคำนวณตามลำดับนี้
   1. ผลของงานแต่ละคน
   2. XP และเลเวลอัป
   3. สิ่งก่อสร้างผลิตของ
   4. มื้อเย็น
   5. 🦠 เชื้อลุกลาม
   6. เหตุการณ์กลางคืน: 🧟 ซอมบี้บุก, ⛈ ฝนตก, 🤒 ไข้, 🚁 เสบียงจากฟ้า หรือคืนที่เงียบ
   7. คนที่ HP หมดจะเสียชีวิต

### 🦠 การติดเชื้อ
- ถูกกัดตอนซอมบี้บุก หรือโดนข่วนตอนออกไปหาเสบียง → มีโอกาสติดเชื้อ
- คนติดเชื้อต้องได้ยาภายใน **2 วัน** ไม่งั้นจะ **กลายเป็นซอมบี้** แล้วทำร้ายคนในศูนย์
- คนแปลกหน้าที่ติดเชื้อมาแล้วจะ **กลายร่างตั้งแต่คืนแรก** ถ้าไม่ได้ยาวันนั้นทันที
- **คนที่ติดเชื้อห้ามขึ้นเฮลิคอปเตอร์!**

### 🧟 ซอมบี้ 5 เลเวล
| Lv | ชนิด | พลัง | ความสามารถพิเศษ | เริ่มโผล่ |
| :---: | :--- | :---: | :--- | :---: |
| 1 | 🧟 ซอมบี้เดิน | 1 | มาเป็นฝูง | วันที่ 3 |
| 2 | 🏃 ซอมบี้วิ่ง | 2 | แนวกั้นเหล็กป้องกันได้แค่ครึ่งเดียว | วันที่ 5 |
| 3 | 💪 ซอมบี้ยักษ์ | 4 | ทุบข้าวของ เศษวัสดุเสียหายตัวละ 2 | วันที่ 7 |
| 4 | 🤮 ซอมบี้พ่นพิษ | 5 | โอกาสติดเชื้อจากการกัด ×2 | วันที่ 10 |
| 5 | 👹 ราชาซอมบี้ | 12 | **บอส** บุกแน่นอนในคืนสุดท้าย | วันที่ 15 |

ตอนบุก เกมจะแสดงว่าฝูงมีตัวอะไรบ้าง เช่น `🧟x3 🏃x4 💪x1 🤮x2 = พลัง 24 vs พลังป้องกัน 23`

### ⚡ พลังพิเศษของผู้รอดชีวิต (Lv 1–5)
| พลัง | ผลต่อเลเวล | งานที่ได้ XP เพิ่ม |
| :--- | :--- | :--- |
| 🎯 แม่นปืน | เฝ้ายามได้พลังป้องกัน +2 | เฝ้ายาม |
| 🧬 ภูมิคุ้มกัน | โอกาสติดเชื้อ −15% | หาเสบียง |
| 🔧 ช่างซ่อม | ค่าก่อสร้าง (เศษวัสดุ) −1 | หาเสบียง |
| 👃 นักสำรวจ | หาเสบียงได้ของเพิ่ม +1 | หาเสบียง |
| 💉 นักวิทยาศาสตร์ | ผลิตยาเองทุก (6 − เลเวล) วัน | รักษา |

ทำงานได้ XP 1 ต่อวัน (ถ้างานตรงกับพลังของตัวเองได้ 2) สะสมครบ `เลเวล × 3` แล้วเลเวลอัป

## ✅ เกณฑ์ Rush00 ทั้ง 8 ข้อ

### 1. Interactive Menu and User Input
หน้าแรกมี 5 ตัวเลือก (ไม่รวมออก) หน้าเล่นเกมมี 6 คำสั่ง และมีเมนูย่อย `อื่นๆ` ใช้ `input()` รับคำสั่ง ใช้ `print()` แสดงผล และวนรับคำสั่งจนกว่าผู้เล่นจะเลือก `0`

### 2. Data Structures and Data Management
- **list:** ผู้รอดชีวิต (`survivors`), สิ่งก่อสร้างที่สร้างแล้ว (`buildings`), ฝูงซอมบี้ของคืนนั้น (list ของเลเวล), สรุปรายวัน (`days`)
- **dict:** ผู้รอดชีวิตแต่ละคน (`{"name", "hp", "skills", "job", "infected", "power", "level", "xp"}`), ทรัพยากร, ซอมบี้แต่ละเลเวล, พลังพิเศษ, งาน, สิ่งก่อสร้าง และตารางเมนู
- **เพิ่ม / ดู / แก้ไข / ลบ:**
  - ผู้รอดชีวิต: รับเข้าศูนย์ / ดูสถานะ / มอบหมายงาน เปลี่ยนชื่อ และเลเวลอัป / ไล่ออก (หรือเสียชีวิต กลายเป็นซอมบี้)
  - สิ่งก่อสร้าง: สร้าง
- ข้อมูลอยู่ตลอดการเล่น และบันทึกลง JSON ทุกครั้งที่เปลี่ยน

### 3. Conditional Logic — กฎที่เปลี่ยนผลลัพธ์
| กฎ | อยู่ที่ |
| :--- | :--- |
| **ทรัพยากรไม่พอ** → สร้างไม่ได้ และสิ่งก่อสร้างแต่ละอย่างสร้างได้ครั้งเดียว | `storage.check_resources`, `camp.do_build` |
| **HP ต่ำกว่า 40** → ออกไปหาเสบียงหรือเฝ้ายามไม่ได้ | `survivors.check_job` |
| **ยาไม่พอ** → มอบงานรักษาเกินจำนวนยาไม่ได้ | `survivors.check_job` |
| **ศูนย์เต็ม** (6 คน) → รับคนเพิ่มไม่ได้ และ **ไล่คนสุดท้ายออกไม่ได้** | `survivors.do_accept_wanderer`, `survivors.do_exile` |
| **1 คน 1 งานต่อวัน** → คนที่ไปตรวจคนแปลกหน้าแล้วทำงานอื่นไม่ได้ | `survivors.do_inspect`, `survivors.assign_job` |
| **ติดเชื้อเกิน 2 วัน** → กลายเป็นซอมบี้ และ **คนติดเชื้อห้ามขึ้นเฮลิคอปเตอร์** | `day.spread_infection`, `day.rescued` |
| **ซอมบี้วิ่ง** → แนวกั้นป้องกันได้ครึ่งเดียว, **ซอมบี้ยักษ์** → ทุบเศษวัสดุ, **ซอมบี้พ่นพิษ** → ติดเชื้อ ×2 | `day.defense`, `day.night_event` |
| **ป้องกันน้อยกว่าพลังฝูง** → เสบียงเสียหายและมีคนถูกกัด | `day.night_event` |
| **ชื่อห้ามว่าง ห้ามซ้ำ และยาวไม่เกิน 12 ตัวอักษร** | `survivors.validate_name` |
| **เลเวลสูงสุด 5** | `powers.gain_xp` |

### 4. Loops and Iteration
- **while:** หน้าแรก, หน้าเล่นเกม (วนจนกว่าจะพักเกมหรือเกมจบ), เมนูอื่นๆ
- **for:** ผลของงานแต่ละคน, XP, สิ่งก่อสร้างผลิตของ, ตรวจคนติดเชื้อ, คำนวณพลังป้องกัน, รวมพลังฝูงซอมบี้, จัดงานอัตโนมัติ, แสดงรายการ และกราฟ
- ทุกลูปมีทางออกชัดเจน และเกมจบที่วันที่ 15 เสมอ

### 5. Functions and Program Organization
แบ่งเป็น 10 โมดูล มีฟังก์ชัน 101 ตัว ตัวอย่าง:
- **รับ parameter:** `do_assign(person, job)`, `job_score(person, job)`, `infect(person, chance, rng, report)`, `gain_xp(person, amount)`, `horde_power(horde)`, `defense(runners)`
- **คืนค่าด้วย return:** `days_left` → จำนวนวันที่อาหาร/น้ำจะพอ, `recommend_job` → งานที่เหมาะที่สุด, `make_horde` → ฝูงซอมบี้, `horde_power` → พลังรวม, `build_cost` → ค่าก่อสร้างหลังส่วนลด, `rescued` → คนที่ได้ขึ้นเฮลิคอปเตอร์, `camp_stats` → dict สถิติ

### 6. Algorithm and Data Processing
| การประมวลผล | อยู่ที่ |
| :--- | :--- |
| **คาดการณ์ว่าอาหาร/น้ำจะพออีกกี่วัน** = ของที่มี ÷ (ใช้ต่อวัน − ผลิตต่อวัน) | `camp.days_left` |
| **แนะนำงาน** = (ทักษะ + โบนัสพลังที่ตรงกับงาน) × ความจำเป็นของงานตอนนี้ (อาหารใกล้หมด ซอมบี้บุก มีคนเจ็บ/ติดเชื้อ) แล้วเลือกงานที่คะแนนสูงสุด | `survivors.job_score`, `survivors.recommend_job` |
| **จัดงานอัตโนมัติ** ให้ทั้งศูนย์ โดยให้คนที่ทักษะรวมสูงสุดเลือกก่อน | `survivors.do_auto_assign` |
| **สุ่มฝูงซอมบี้** ตามวัน (เลเวลสูงโผล่น้อยกว่า) และ **รวมพลังของฝูง** | `day.make_horde`, `day.horde_power` |
| **เลือกคนรักษา** = คนติดเชื้อที่ใกล้กลายร่างที่สุด (ค่าสูงสุด) ไม่งั้นคนที่ HP ต่ำสุด (ค่าต่ำสุด) | `day.heal` |
| **ประวัติผลเกม:** จำนวนเกมที่เล่นจบ เกมที่รอด ผลดีที่สุด (ดาว แล้วจำนวนคน) และค่าเฉลี่ยคนที่รอด | `menu.history_summary` |
| **สถิติ:** ของที่หาได้ อัตราต้านการบุก อัตรารักษาการติดเชื้อ คนที่เก่งที่สุดแต่ละทักษะ คนที่พลังเลเวลสูงสุด ฝูงที่ใหญ่ที่สุด และกราฟอาหารรายวัน | `day.camp_stats`, `day.camp_log` |

### 7. Input Validation and Error Handling
- เลือกเมนูที่ไม่มี → "ไม่มีเมนูนี้" แล้วกลับมาให้เลือกใหม่
- พิมพ์ตัวอักษรแทนตัวเลข → ดักด้วย `try/except ValueError` แจ้ง "กรุณากรอกเป็นตัวเลข"
- เลขเกินหรือต่ำกว่าช่วง → "ไม่มีหมายเลขนี้" และพิมพ์ `0` เพื่อยกเลิกได้ทุกที่
- ทำกับข้อมูลที่ไม่มี (ประตูว่าง, ตรวจซ้ำ, ไม่มีคนว่างให้ไปตรวจ) → แจ้งเหตุผล
- จบวันทั้งที่ยังมีคนไม่มีงาน → ถามยืนยันก่อน
- ไฟล์เซฟหายหรือเสีย → เริ่มเกมใหม่แทน, ไฟล์ประวัติเสีย → ถือว่ายังไม่มีประวัติ
- เริ่มเกมใหม่ทั้งที่มีเกมค้าง → ถามยืนยันก่อน
- Ctrl+C / Ctrl+D → บันทึกแล้วออกโดยไม่ crash

### 8. Functional Application
ตัวอย่างการเล่นตั้งแต่ต้นจนจบ:
1. ดูผู้รอดชีวิต 3 คนพร้อมพลังพิเศษ: 👃 นักสำรวจ, 💉 นักวิทยาศาสตร์, 🎯 แม่นปืน
2. ลองสร้างแนวกั้นเหล็ก → **เศษวัสดุไม่พอ**
3. มีคนมาที่ประตู → ให้เคนตรวจร่างกาย → **🦠 พบรอยกัด!** → ไม่รับ
4. จัดงานอัตโนมัติ → จบวัน → ได้เสบียง และมีคนเลเวลอัป
5. วันที่ 7 → `🧟x3 🏃x3 💪x3 = พลัง 21 vs 18` → ซอมบี้ทะลวงเข้ามา หมอถูกกัดจนติดเชื้อ → วันต่อมามอบงานรักษาด่วน
6. คืนสุดท้าย 👹 ราชาซอมบี้บุก → 🚁 เฮลิคอปเตอร์มารับ → ได้ดาวตามจำนวนคนที่ไม่ติดเชื้อ
7. บันทึกศูนย์พักพิง: สถิติและกราฟ → ออกแล้วเปิดใหม่ ข้อมูลยังอยู่
8. หน้าแรก → 🏆 ผลเกมที่ผ่านมา: เห็นผลเกมนี้ ผลดีที่สุด และค่าเฉลี่ย
