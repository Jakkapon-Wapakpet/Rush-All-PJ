# 👻 มิติผี (GHOST REALM)

เกมเอาชีวิตรอดในมิติผีที่เล่นใน Terminal บริหารคน เสบียง และคนที่ถูกผีสิง ให้รอดจนประตูมิติเปิด
ผลงาน **Rush00 · 42 Bangkok**

> คืนวันฮาโลวีน เพื่อน 3 คนเดินเข้าบ้านผีสิงด้วยบัตรฟรีจากคนที่ไม่มีเงา
> พอลืมตาขึ้นมา... ทุกคนก็ติดอยู่ในมิติผีแล้ว

## 🚀 วิธีรัน

ใช้ Python 3.6 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้แค่ standard library)

```bash
cd rush
python3 main.py
```

เวอร์ชันหน้าต่าง (Bonus) ต้องมี Tkinter และ Pillow 9.1 ขึ้นไป

```bash
cd rush
python3 gui.py
```

รันเทสต์

```bash
cd rush
python3 -m unittest test_campaign -v
```

## 🎮 เล่นยังไง

- เลือกระดับ: ง่าย 15 วัน / ปกติ 20 วัน / ฝันร้าย 25 วัน
- ทุกวันมอบงานให้คนในศาลา: หาของ เฝ้ายาม ประพรมน้ำมนต์ หรือพัก
- ใช้ธูปเทียนสร้างสายสิญจน์ แปลงผัก ถังน้ำฝน ศาลพระภูมิ
- ตัดสินใจว่าจะรับคนแปลกหน้าที่ประตูไหม เขาอาจถูกผีสิงมา
- พอจบวัน ทุกคนต้องกินและดื่ม แล้วตอนกลางคืนผีอาจบุก
- รอดครบจำนวนวันแล้วประตูมิติจะเปิด ยิ่งพากลับบ้านได้มาก ยิ่งได้ดาวมาก (สูงสุด ⭐⭐⭐)

เกมรองรับภาษาไทยและอังกฤษ และบันทึกความคืบหน้าอัตโนมัติ

## 📁 โครงสร้าง

```
rush/
├── main.py          จุดเริ่มเกม
├── menu.py          หน้าแรก และหน้าเล่นแต่ละวัน
├── survivors.py     คนในศาลา: งาน ประตู เปลี่ยนชื่อ ไล่ออก
├── sala.py          ทรัพยากรและสิ่งก่อสร้าง
├── realm.py         ระบบเสริม: ลาง ของแก้ผี ไฟ บนบาน ตั๋ว
├── day.py           จบวัน: คำนวณผลทั้งหมด ผีบุก ชนะ/แพ้
├── data.py          ค่าคงที่ของเกม
├── storage.py       สถานะเกม เซฟ/โหลด JSON
├── language.py      ระบบสองภาษา
├── ui.py            ตัวช่วยรับ input และแบนเนอร์
├── gui.py, gui_theme.py, talung_ui/   เวอร์ชันหน้าต่าง (Bonus)
├── assets/          รูปภาพ
└── test_campaign.py เทสต์
```
