# ⚒ OVERGEAR — ร้านตีอาวุธร้านสุดท้าย

**เกมบริหารร้านตีอาวุธแฟนตาซีตะวันตก: ตีอาวุธให้ทหารและผู้กล้า ก่อนมังกรบุกหมู่บ้านในวันที่ 30**

> *"ดาบทุกเล่มที่ขายไป จะกลับมา... หรือไม่กลับมา"*
> *"Every blade you sell comes back... or doesn't."*

คุณเป็นช่างตีเหล็กคนสุดท้ายของหมู่บ้านชายแดน ผู้กล้าที่ผ่านมาซื้ออาวุธไปปราบสัตว์ประหลาด และ **อีก 30 วันมังกรจะบุกหมู่บ้าน**
ต้องหาเงิน สร้างชื่อเสียง ติดอาวุธให้ทหารและผู้กล้า แล้วตีอาวุธระดับ **ตำนาน / เทพนิยาย** ให้ผู้กล้าแชมป์ให้ทันก่อนวันนั้น

จุดต่างจากเกมร้านค้าทั่วไป: **อาวุธที่ขายไปไม่ได้หายไปเฉยๆ**
- อาวุธที่ส่งให้ **ผู้กล้า** จะถูกใช้ออกล่าจริงทุกคืน ของดีทำให้ผู้กล้ารอด เลเวลขึ้น นำวัตถุดิบหายากกลับมาขาย ของแย่ทำให้ผู้กล้าตายและร้านเสียชื่อ
- อาวุธที่ส่งให้ **ทหารรักษาเมือง** จะถูกเก็บไว้สู้มังกร
- วันที่ 30 ทุกอย่างที่ตีมา (ทหาร + ผู้กล้าที่ยังมีชีวิต + แชมป์) รวมเป็นพลังป้องกันหมู่บ้าน

เกมรองรับภาษาไทยและอังกฤษ และบันทึกความคืบหน้าลงไฟล์ JSON อัตโนมัติ

## 🚀 วิธีรัน

ต้องใช้ **Python 3.6 ขึ้นไป** และไม่ต้องติดตั้ง package เพิ่ม (ใช้แค่ standard library: `os`, `json`, `copy`, `random`, `math`, `sys`)

```bash
cd overgear
python3 main.py
```

(รันจากโฟลเดอร์อื่นก็ได้ เช่น `python3 overgear/main.py` ไฟล์เซฟจะอยู่ในโฟลเดอร์ `overgear/` เสมอ)

**จำลองเล่นเพื่อปรับสมดุล:**

```bash
python3 simulate.py 300
```

> **เริ่มเกมใหม่:** เลือก `2. เริ่มเกมใหม่` ที่หน้าแรก หรือลบไฟล์ `overgear_save.json` (ประวัติผลเกมอยู่ใน `overgear_history.json`)

### ในแต่ละวัน
1. **📋 รับออเดอร์:** ลูกค้า 4 คนบนกระดาน (เรียงจากคุ้มที่สุดให้แล้ว) แต่ตีได้แค่วันละ 2 ครั้ง (มีลูกมือ +1) ต้องเลือกว่าจะเอางานเงินดี งานเพิ่มชื่อเสียง หรืองานผู้กล้า
   - ออเดอร์ระบุ **แบบอาวุธ + เกรดขั้นต่ำ** และอาจมี **คมขั้นต่ำ / น้ำหนักไม่เกิน** และ **กำหนดส่ง**
   - ออเดอร์ที่ยังทำไม่ได้ (ไม่มีแม่พิมพ์ / ของไม่มีขาย) มีเครื่องหมาย ✖ และถามยืนยันก่อนรับ
2. **🛒 ซื้อวัตถุดิบ:** ราคาขึ้นลงทุกวันตามข่าว และมี **ข่าวลือของพรุ่งนี้** ให้ตุนของให้ถูกจังหวะ (เช่น พรุ่งนี้เหมืองเงินถล่ม → ซื้อเงินวันนี้)
3. **🔥 ตีอาวุธ:** เลือก **ใบมีด + ด้าม + เครื่องประดับ** (หรือกด "ตีตามสูตรแนะนำ" ให้เกมหาสูตรกำไรสูงสุดและซื้อของที่ขาดให้) แล้วเลือก
   - **ตีเอง (มินิเกมเตาหลอม):** แม่นได้ถึง 10 และเป็นทางเดียวที่จะได้เทพนิยาย
   - **ตีอัตโนมัติ:** ความแม่นคงที่ 4 (มีลูกมือ 7)
4. **ส่งของ:** ได้เงิน + ชื่อเสียง เกรดเกินสเปกได้โบนัส **+10% และ +1 ชื่อเสียงต่อขั้น** ส่งช้า (−3) หรือยกเลิก (−2) เสียชื่อ
5. **🌙 จบวัน → กลางคืนผู้กล้าออกล่า:** ผู้กล้าที่ถืออาวุธของเราออกผจญภัยจริง
   - **รอด** → ชื่อเสียง + เลเวลขึ้น + อาจนำวัตถุดิบหายากมาขายพรุ่งนี้
   - **แพ้** → บาดเจ็บพัก 2 วัน หรือ **ตาย** (ร้านเสียชื่อ −5 และผู้กล้ามาน้อยลง)
   - อาวุธสึกทุกครั้งที่ใช้ หักแล้วผู้กล้าจะกลับมา **จ้างซ่อม** (ใช้เหล็ก 1 + แรงตี 1)

### 🔥 มินิเกมเตาหลอม — ตีขณะเหล็กยังร้อน
```
 🌡 [▓▓▓▓▓▓▓···] 7/10 ร้อนพอดี
 ⚒ ขึ้นรูป [██░░░░] 2/6   🪨 ถ่านเหลือ 6 จังหวะ
 1. 🔨 ตีแรง  💡 แนะนำ      (+2 ขึ้นรูป เหล็กเย็นลงเร็ว)
 2. 🔧 ตีเบา                 (+1 ขึ้นรูป)
 3. 🔥 สูบลมเผาไฟ            (ร้อนขึ้น 2-4)
 4. 💨 รอให้เย็นลง
```
- ต้องตีขึ้นรูปให้ครบ 6 ก่อนถ่านหมด (6 จังหวะ + เลเวลเตา)
- ตีตอนความร้อน **6-8 = สมบูรณ์แบบ**, 4-9 = ดี, นอกนั้น = แย่ ทุกจังหวะเหล็กเย็นลง 1-2 (ระดับง่าย 1)
- ความแม่น 0-10 = คะแนนจังหวะที่ตี และเกมมีปุ่ม 💡 แนะนำท่าให้

## ⭐ เกรดอาวุธ 5 ระดับ

| เกรด | ตัวคูณพลัง | ตัวคูณราคา | คะแนนขั้นต่ำ | ได้มาอย่างไร |
| :--- | :---: | :---: | :---: | :--- |
| ⚪ ธรรมดา (Common) | ×1.0 | ×1 | 0 | ตีด้วยวัตถุดิบอะไรก็ได้ |
| 🔵 แรร์ (Rare) | ×1.25 | ×2 | 9 | ตีดี (เหล็กได้สูงสุดเกรดนี้) |
| 🟣 อีปิค (Epic) | ×1.6 | ×4 | 15 | ใบมีดเงินขึ้นไป + ตีดีมาก |
| 🟠 ตำนาน (Legendary) | ×2.2 | ×10 | 21 | ต้องมีวัตถุดิบตำนานอย่างน้อย 1 ชิ้น (ได้จากผู้กล้าที่รอดกลับมาเท่านั้น) |
| 🔴 เทพนิยาย (Mythic) | ×3.0 | ×30 | 27 | วัตถุดิบตำนาน 3 ชิ้น + เตาเลเวล 4 + **ตีสมบูรณ์แบบทุกจังหวะ** |

**วิธีคำนวณเกรด** (`forge.quality_score`, `forge.grade_cap`, `forge.roll_grade`)
- **คะแนนคุณภาพ** = คะแนนวัตถุดิบ (ใบมีด + ด้าม + เครื่องประดับ) + (เลเวลเตา − 1) × 2 + ความแม่นในมินิเกม (0-10)
- **เพดานตามวัตถุดิบ:** เหล็ก → แรร์, เงิน → อีปิค, มิธริล → ตำนาน, เหล็กดาวตก → เทพนิยาย และถ้าไม่มีของตำนานเลยจะไม่เกินอีปิค
- **ตีวิกฤต (Critical Forge):** โอกาส 5% ที่เกรดขึ้นอีก 1 ขั้น (ไม่เกินเพดาน)
- **ค่าพลัง** = (คม + ทนทาน) × ตัวคูณเกรด ซึ่งใช้ทั้งการล่าของผู้กล้าและการป้องกันหมู่บ้าน
- ระดับนรกเหล็กกล้าเกณฑ์คะแนนทุกเกรด +2

| วัตถุดิบ | ส่วน | คะแนน | ที่มา |
| :--- | :--- | :---: | :--- |
| ⬛ เหล็ก / 🥈 เงิน | ใบมีด | 1 / 4 | ตลาด |
| 💠 มิธริล | ใบมีด | 7 | คาราวานคนแคระ หรือผู้กล้านำมาขาย |
| ☄ เหล็กดาวตก ★ | ใบมีด | 10 | ผู้กล้าเท่านั้น (ภารกิจหลุมอุกกาบาตเพลิง) |
| 🪵 ไม้โอ๊ก / 🌲 ไม้เหล็ก | ด้าม | 0 / 2 | ตลาด |
| 🌳 แก่นไม้เอนท์ ★ | ด้าม | 4 | ผู้กล้าเท่านั้น (ภารกิจป่าเอนท์โบราณ) |
| 💎 ทับทิม / 🪨 หินรูน | เครื่องประดับ | 2 | ตลาด (คม +2 / ทน +2) |
| 🪶 ขนนกฟีนิกซ์ ★ | เครื่องประดับ | 4 | ผู้กล้าเท่านั้น (ภารกิจยอดเขาฟีนิกซ์) |

## ⚔ ผู้กล้า
- เลือกล่าสัตว์ประหลาดตามเลเวล: 👺 ก็อบลิน → 🐺 หมาป่าดำ → 👹 โทรลล์ → 🦇 ไวเวิร์น → 💀 ลิช (บาร์บาเรียนบ้าบิ่น ล่าสูงกว่า 1 ขั้น)
- **โอกาสชนะ** = 1 − 0.3 ÷ (พลังผู้กล้า/ความแข็ง)² (5%-97%) โดย **พลังผู้กล้า = เลเวล × 3 + พลังอาวุธของเรา** อาวุธดีจึงทำให้ผู้กล้ารอดจริง
- **ภารกิจตำนาน:** จ่ายค่าจ้างส่งผู้กล้าที่ถืออาวุธเราไปหาวัตถุดิบตำนาน (เกมบอกโอกาสชนะให้ก่อน)
- **มอบอาวุธ** จากชั้นวางให้ผู้กล้าได้ (ชื่อเสียง +1) และ **แต่งตั้งแชมป์** 👑 ที่จะสู้มังกร
- ผู้กล้าที่ไม่มีอาวุธเกิน 4 วันจะไปซื้อร้านคู่แข่ง ชื่อเสียงยิ่งสูง ผู้กล้ายิ่งมาที่เมืองมาก (2 + ชื่อเสียง/25 คน สูงสุด 6)

## 🐉 ฉากจบวันที่ 30
**พลังป้องกัน** = อาวุธในคลังทหาร × 0.4 + ผู้กล้าที่ถืออาวุธเรา + **แชมป์ × 2** (แชมป์ถืออาวุธเทพนิยาย **× 2 อีกชั้น**) เทียบกับพลังมังกร (แกว่ง ±10%)

| พลังป้องกัน / มังกร | ผล |
| :--- | :--- |
| ≥ 100% | ⭐⭐⭐ หมู่บ้านรอดปลอดภัย (ถ้าแชมป์ถืออาวุธเทพนิยาย = 🐉 **ปราบมังกร!**) |
| ≥ 65% | ⭐⭐ รอด แต่บ้านเรือนเสียหาย |
| ≥ 35% | ⭐ ยับเยิน ชาวบ้านหนีทัน |
| < 35% | หมู่บ้านล่มสลาย |

| `day.py` | เริ่มเกม/เช้าวันใหม่ จบวัน ค่าใช้จ่าย ฉากจบมังกร และบันทึกร้าน (สถิติ + กราฟ) |
| `data.py` | ข้อมูลคงที่: เกรด แม่พิมพ์ วัตถุดิบ ลูกค้า ผู้กล้า สัตว์ประหลาด ข่าว ระดับความยาก |
| `storage.py` | สถานะเกม เงิน/ชื่อเสียง/คลัง เซฟ-โหลด JSON และประวัติผลเกม |
| `ui.py` | ตัวช่วยรับ input (เลือกจากรายการ, ตัวเลขในช่วง, y/n) และแถบกราฟ |
| `language.py` | ระบบสองภาษา `get_text(th, en)` และล้างหน้าจอ |
| `simulate.py` | สคริปต์จำลองเล่นหลายร้อยเกมด้วยบอท 2 แบบ เพื่อปรับสมดุล |

**แยกกฎออกจากหน้าจอ:** กฎและการเปลี่ยนข้อมูลทั้งหมดอยู่ในฟังก์ชัน `do_*` 25 ตัวที่ **ไม่มี `input`/`print`** และคืนข้อความผิดพลาด (หรือ `""` ถ้าสำเร็จ) เช่น `shop.do_deliver(order, weapon)`, `forge.do_strike(action)`, `day.do_end_day(rng)` สคริปต์จำลองเล่นเรียกแค่ฟังก์ชันเหล่านี้ จึงต่อ GUI (Tkinter) ทีหลังได้โดยไม่ต้องแก้กฎ

## ✅ เกณฑ์ Rush00 ทั้ง 8 ข้อ

### 1. Interactive Menu and User Input
หน้าแรกมี 5 ตัวเลือก (ไม่รวมออก) หน้าร้านมี 8 คำสั่ง และมีเมนูย่อย: กระดานออเดอร์, ตลาด, ตีอาวุธ + มินิเกม, ชั้นวางอาวุธ, ผู้กล้า, ลงทุน, อื่นๆ, เลือกระดับความยาก, เลือกภาษา ทุกเมนูวนรับคำสั่งจนกว่าผู้เล่นจะกด `0` (`menu.title_menu`, `menu.day_menu`, `shop.orders_menu`, `market.market_menu`, `heroes.heroes_menu`, `menu.rack_menu`, `menu.invest_menu`, `forge.play_minigame`)

### 2. Data Structures and Data Management
- **list:** อาวุธบนชั้นวาง (`weapons`), ออเดอร์ที่รับ (`orders`), กระดานลูกค้า (`board`), ผู้กล้า (`heroes`), คลังทหาร (`garrison`), ของจากผู้กล้า (`offers`), ผู้กล้าที่ตาย (`fallen`), สรุปรายวัน (`log.days`), แม่พิมพ์ (`molds`)
- **dict:** อาวุธแต่ละชิ้น (`{"type", "grade", "sharp", "sturdy", "weight", "power", "dur", "parts", ...}`), ออเดอร์ (`{"kind", "type", "min_grade", "min_sharp", "max_weight", "pay", "due", ...}`), ผู้กล้า, คลังวัตถุดิบ, ราคาวันนี้, เซสชันมินิเกม, และข้อมูลคงที่ใน `data.py` (เกรด แม่พิมพ์ วัตถุดิบ ลูกค้า ข่าว ระดับความยาก)
- **เพิ่ม / ดู / แก้ไข / ลบ:**
  - อาวุธ: ตี (เพิ่ม) / ดูชั้นวาง / **สลักชื่อ** (แก้) / ขาย หลอมคืน ส่งของ บริจาค (ลบ)
  - ออเดอร์: รับจากกระดาน (เพิ่ม) / ดู / ซ่อม-ส่ง / **ยกเลิก** (ลบ)
  - วัตถุดิบ: ซื้อ / ดูคลัง / ขายคืน
  - ผู้กล้า: มาที่เมือง / ดู / สั่งงาน มอบอาวุธ แต่งตั้งแชมป์ (แก้) / ตายหรือออกจากเมือง (ลบ)
- ข้อมูลอยู่ตลอดการเล่น และบันทึกลง JSON ทุกครั้งที่เปลี่ยน

### 3. Conditional Logic — กฎที่เปลี่ยนผลลัพธ์
| กฎ | อยู่ที่ |
| :--- | :--- |
| **เงินไม่พอ** → ซื้อ/ลงทุน/ส่งภารกิจไม่ได้ | `storage.check_gold` |
| **วัตถุดิบไม่ครบ** หรือใส่ผิดช่อง → ตีไม่ได้ | `storage.check_materials`, `forge.check_forge` |
| **คลังเต็ม / ชั้นวางเต็ม** → ซื้อหรือตีเพิ่มไม่ได้ | `storage.check_space`, `forge.check_forge` |
| **ตีครบแรงของวัน** (2 ครั้ง, ลูกมือ +1) | `forge.check_forge`, `shop.do_repair` |
| **ไม่มีแม่พิมพ์** → ทำอาวุธแบบนั้นไม่ได้ | `forge.check_forge`, `shop.cant_make_reason` |
| **เพดานเกรดตามวัตถุดิบ**, ไม่มีของตำนาน → ไม่เกินอีปิค, เทพนิยายต้องครบ 3 เงื่อนไข | `forge.grade_cap` |
| **ตีวิกฤต 5%** → เกรด +1 (ไม่เกินเพดาน) | `forge.roll_grade` |
| **ความร้อนตอนตี** → สมบูรณ์แบบ / ดี / แย่ | `forge.rate_heat` |
| **ไม่ตรงสเปก** (แบบ เกรด คม น้ำหนัก) → ส่งไม่ได้ | `shop.match_order` |
| **เลยกำหนดส่ง** → เสียชื่อเสียง, **ยกเลิกเอง** → เสียชื่อเสียง | `shop.expire_orders`, `shop.do_cancel` |
| **ชื่อเสียงไม่พอ** → ขุนนาง VIP ไม่มา, ผู้กล้ามาน้อย | `shop.fill_board`, `heroes.max_heroes` |
| **ร้านคู่แข่งตัดราคา** → ค่าจ้าง −20% ยกเว้นชื่อเสียง 40+ | `shop.pay_factor` |
| **คาราวาน** → มิธริลมีขายเฉพาะวันนั้น, ของตำนานไม่มีขายในตลาด | `market.available` |
| **ผู้กล้าแพ้** → บาดเจ็บหรือตาย (พลังน้อยกว่าความแข็งตายง่ายขึ้น), **อาวุธหัก** → ต้องซ่อม | `heroes.hunt_result`, `heroes.death_chance` |
| **ผู้กล้าไม่มีอาวุธเกิน 4 วัน** → ไปร้านคู่แข่ง | `heroes.morning_heroes` |
| **ภารกิจตำนาน** ต้องถืออาวุธเราที่ไม่หักและไม่บาดเจ็บ | `heroes.do_set_task` |
| **เงินไม่พอจ่ายค่าเช่า** → เสียชื่อเสียง ลูกมือลาออก | `day.pay_upkeep` |
| **ชื่อที่สลัก** ห้ามว่าง ห้ามซ้ำ ยาวไม่เกิน 14 ตัว | `forge.validate_engraving` |
| **พลังป้องกัน/มังกร** → ดาว 0-3 และปราบมังกรด้วยเทพนิยาย | `day.ending_grade`, `day.do_final_battle` |

### 4. Loops and Iteration
- **while:** หน้าแรก, หน้าร้าน (วนจนกว่าจะพักเกมหรือเกมจบวันที่ 30), ทุกเมนูย่อย, มินิเกม (วนจนขึ้นรูปเสร็จหรือถ่านหมด), เรียงออเดอร์, เลเวลอัป, บอทในสคริปต์จำลอง
- **for:** ผู้กล้าออกล่าทุกคน, ตรวจออเดอร์หมดเวลา, ลองทุกสูตร (ใบมีด × ด้าม × เครื่องประดับ), สร้างราคาวัตถุดิบ, รวมพลังป้องกัน, แสดงรายการ และกราฟ
- ทุกลูปมีทางออกชัดเจน และเกมจบที่วันที่ 30 เสมอ

### 5. Functions and Program Organization
แบ่งเป็น 11 โมดูล (ไม่นับสคริปต์จำลอง) มีฟังก์ชัน 181 ตัว ตัวอย่างตามแผน:
- `forge.make_weapon(mold, parts, accuracy, perfect, rng)` — ตีอาวุธจากส่วนประกอบ (แผนเรียก `forge(parts)`)
- `forge.roll_grade(quality, cap, rng)` → (เกรด, ตีวิกฤตไหม)
- `market.price_today(key)` → ราคาวันนี้
- `shop.match_order(weapon, order)` → เหตุผลที่ไม่ผ่านสเปก หรือ `""`
- `heroes.hunt_result(hero, rng)` → ผลการล่า (ชนะ/บาดเจ็บ/ตาย + ของที่ได้)
- อื่นๆ ที่รับ parameter และคืนค่า: `forge.grade_cap`, `forge.quality_score`, `forge.weapon_stats`, `heroes.win_chance`, `shop.recommend_recipe`, `shop.order_worth`, `day.ending_grade`, `day.defense_breakdown`

### 6. Algorithm and Data Processing
| การประมวลผล | อยู่ที่ |
| :--- | :--- |
| **คำนวณค่าพลังและเกรด:** คะแนนคุณภาพ → เกรดตามเกณฑ์ → ตัดด้วยเพดาน → ตีวิกฤต แล้วค่าพลัง = (คม + ทน) × ตัวคูณเกรด | `forge.quality_score`, `forge.grade_from_score`, `forge.roll_grade`, `forge.weapon_stats` |
| **แนะนำสูตรกำไรสูงสุดต่อออเดอร์:** ลองทุกสูตร 48 แบบ คัดที่มีของ/ซื้อได้วันนี้ เงินพอ และเกรด/คม/น้ำหนักที่คาดว่าจะได้ผ่านสเปก แล้วเลือกต้นทุนต่ำสุด (เท่ากันเลือกพลังสูงกว่า) | `shop.recommend_recipe` |
| **เรียงออเดอร์ตามความคุ้ม** = กำไร + ชื่อเสียง × 6 + โบนัสผู้กล้า/ทหาร (เรียงแบบเลือกค่าสูงสุดทีละตัว) | `shop.order_worth`, `shop.sorted_board` |
| **คาดการณ์เงินสด 5 วัน** = เงินตอนนี้ + ค่าจ้างออเดอร์ที่ครบกำหนด − ค่าใช้จ่ายรายวัน | `shop.cash_forecast` |
| **แนะนำท่าในมินิเกม** จากความร้อน จังหวะที่เหลือ และงานที่เหลือ | `forge.suggest_action` |
| **โอกาสชนะของผู้กล้า** และการเลือกสัตว์ประหลาดตามเลเวล | `heroes.win_chance`, `heroes.hunt_target` |
| **พลังป้องกันหมู่บ้าน** และคาดการณ์ดาวถ้ามังกรมาวันนี้ | `day.defense_breakdown`, `menu.forecast` |
| **ราคาวันนี้** = ราคาฐาน × ความผันผวน × ผลข่าว พร้อมลูกศรขึ้น/ลง | `market.make_prices`, `market.trend` |
| **สถิติร้าน:** เกรดที่ตีได้ อัตราผู้กล้าชนะ รายรับ-รายจ่าย อาวุธดีที่สุด และกราฟเงินรายวัน | `day.shop_stats`, `day.shop_log` |
| **ประวัติผลเกม:** จำนวนเกม เกมที่หมู่บ้านรอด ผลดีที่สุด ดาวเฉลี่ย จำนวนครั้งที่ปราบมังกร | `menu.history_summary` |

### 7. Input Validation and Error Handling
- เลือกเมนูที่ไม่มี → "ไม่มีเมนูนี้" แล้วกลับมาให้เลือกใหม่
- พิมพ์ตัวอักษรแทนตัวเลข → ดักด้วย `try/except ValueError` แจ้ง "กรุณากรอกเป็นตัวเลข"
- เลขเกินหรือต่ำกว่าช่วง → แจ้งช่วงที่ถูก และพิมพ์ `0` เพื่อ **ยกเลิกได้ทุกที่** (`ui.choose_from_list`, `ui.ask_int`)
- ทำกับข้อมูลที่ไม่มี (ชั้นวางว่าง, ไม่มีออเดอร์, ไม่มีผู้กล้า) → แจ้งเหตุผล ไม่ crash
- ทุก `do_*` ตรวจกฎก่อนแก้ข้อมูล และคืนข้อความผิดพลาดที่อ่านเข้าใจได้สองภาษา
- รับออเดอร์ที่ยังทำไม่ได้, ยกเลิกออเดอร์, ขาย/หลอมอาวุธ, จบวันทั้งที่มีออเดอร์ครบกำหนดหรือยังมีแรงตี, สู้มังกรโดยไม่มีแชมป์ → **ถามยืนยันก่อน**
- ไฟล์เซฟหาย/เสีย/ผิดรูปแบบ → เริ่มเกมใหม่แทน (`storage.valid_save`), ไฟล์ประวัติเสีย → ถือว่ายังไม่มีประวัติ
- ปิดเกมกลางมินิเกม → เหล็กยังค้างบนทั่ง เปิดเกมใหม่ตีต่อได้ (หรือจบวันแล้วเกมตีให้จบเอง)
- Ctrl+C / Ctrl+D → บันทึกแล้วออกโดยไม่ crash

### 8. Functional Application
ตัวอย่างการเล่นตั้งแต่ต้นจนจบ:
1. เริ่มเกมระดับปกติ กระดานมีผู้กล้า 🛡 ยอริก อยากได้ดาบ และทหารสั่ง "ดาบ 🔵แรร์+ คม 5+" → รับทั้งสองใบ
2. ลองรับออเดอร์หอก → ⚠ "ยังไม่มีแม่พิมพ์หอก" ไม่รับ
3. ตีตามสูตรแนะนำ: ⬛ เหล็ก + 🪵 ไม้โอ๊ก → มินิเกม ตีแรงตอนร้อน 7 = สมบูรณ์แบบ → 💥 **ตีวิกฤต!** ได้ดาบ 🔵แรร์ → ส่งให้ทหาร (เข้าคลังทหาร)
4. จบวัน → คืนนั้นยอริกถือดาบของเราไปปราบ 👺 ก็อบลิน ชนะ เลเวลขึ้น
5. ดูข่าวลือ "พรุ่งนี้เหมืองเงินถล่ม" → ตุนเงินไว้ก่อน, วันคาราวานมา ซื้อมิธริล
6. ส่งผู้กล้าเลเวลสูงไป ☄ หลุมอุกกาบาตเพลิง ได้เหล็กดาวตกกลับมา → อัปเกรดเตาเป็นเลเวล 4
7. ตีเหล็กดาวตก + แก่นไม้เอนท์ + ขนนกฟีนิกซ์ ตีสมบูรณ์แบบทุกจังหวะ → 🔴 **เทพนิยาย** → มอบให้แชมป์ 👑
8. วันที่ 30 มังกรบุก → ทหาร + ผู้กล้า + แชมป์ เทียบพลังมังกร → ⭐⭐⭐ และ 🐉 ปราบมังกร → ออกแล้วเปิดใหม่ ข้อมูลยังอยู่ และเห็นผลใน 🏆 ผลเกมที่ผ่านมา

(ป้องกัน/มังกร = ค่าเฉลี่ยพลังป้องกันเทียบพลังมังกร, ตำนาน/เทพนิยาย = % ของเกมที่ตีอาวุธเกรดนั้นได้อย่างน้อย 1 ชิ้น)

- **ง่าย** ใช้เดโม: กดง่ายๆ ก็รอดทุกเกม และผู้เล่นที่วางแผนได้ลุ้นตีเทพนิยาย/ปราบมังกรบ่อย
- **ปกติ** กดง่ายๆ ได้แค่ ⭐ (หมู่บ้านยับเยิน) เพราะไม่มีของตำนาน แชมป์อ่อน และผู้กล้าตายเยอะ ต้องวางแผนถึงจะรอดสวยๆ
- **นรกเหล็กกล้า** แม้วางแผนดีก็รอดครบ 3 ดาวแค่ 40% เกณฑ์เกรดที่สูงขึ้นทำให้ตีตำนานยากกว่าระดับปกติเกือบครึ่ง
- 🔴 **เทพนิยาย** ตั้งใจให้เป็นเป้าหมายท้าทาย (ต้องเก็บของตำนานครบ 3 ชิ้น อัปเกรดเตาถึงเลเวล 4 และตีสมบูรณ์แบบทุกจังหวะ) บอทวางแผนทำได้ 1-23% ผู้เล่นที่ตั้งใจเก็บของตำนานตั้งแต่เนิ่นๆ ทำได้บ่อยกว่านี้
- ผู้กล้าตายเฉลี่ย 3.5-6 คนต่อเกม เป็นไปตามธีม *"ดาบทุกเล่มที่ขายไป จะกลับมา... หรือไม่กลับมา"* อาวุธยิ่งดี ผู้กล้ายิ่งรอด
- บอทวางแผนเหลือเงินเยอะเพราะตีได้จำกัดวันละ 3 ครั้ง (เงินช่วยได้ถึงจุดหนึ่ง แต่พลังป้องกันมาจากอาวุธที่ตี ไม่ได้มาจากเงิน)

## ⭐ ส่วนเสริม (Bonus)

- **บันทึก/โหลดเกมด้วย JSON** อัตโนมัติทุกครั้งที่ข้อมูลเปลี่ยน (รวมถึงตอนตีค้างในมินิเกม)
- **ประวัติผลเกมทุกเกม** พร้อมผลดีที่สุด ดาวเฉลี่ย และจำนวนครั้งที่ปราบมังกร
- **บันทึกร้าน** สถิติ + กราฟเงินรายวัน และหน้าคาดการณ์เงินสด/พลังป้องกัน
- **มินิเกมเตาหลอม** พร้อมระบบแนะนำท่า และ **ตีวิกฤต 5%**
- **ระบบแนะนำสูตรกำไรสูงสุด** ที่ซื้อวัตถุดิบที่ขาดให้อัตโนมัติ
- **ข่าวลือล่วงหน้า 1 วัน** ให้วางแผนตุนวัตถุดิบ
- **3 ระดับความยาก** ปรับสมดุลด้วยการจำลองเล่น 300 เกมต่อระดับ
- **ระบบสองภาษา** ไทย/อังกฤษ
- กฎทั้งหมดแยกเป็น `do_*` ไม่มี `input`/`print` พร้อมต่อ **GUI (Tkinter)** ในรอบถัดไป
