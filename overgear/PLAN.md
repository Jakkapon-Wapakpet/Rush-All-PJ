# ⚒ OVERGEAR — แผนเกม (ยังไม่ได้เริ่มเขียนโค้ด)

**แนว:** บริหารร้านตีอาวุธ แฟนตาซีตะวันตก (ดาบ ขวาน มิธริล มังกร)
**สโลแกน (ตัวเลือก):** *"Every blade you sell comes back... or doesn't."*
**ข้อกำหนด:** Rush00 (Python 3 + standard library, เกณฑ์ 8 ข้อ) เล่นใน Terminal ได้ครบ, GUI Tkinter เป็น Bonus, สองภาษาไทย/อังกฤษ, เซฟ JSON

---

## เรื่องย่อ
คุณเป็นช่างตีเหล็กคนสุดท้ายของหมู่บ้านชายแดน ผู้กล้าที่ผ่านมาซื้ออาวุธไปปราบสัตว์ประหลาด และ **อีก 30 วันมังกรจะบุกหมู่บ้าน**
ต้องหาเงิน สร้างชื่อเสียง และตีอาวุธระดับ **ตำนาน / เทพนิยาย** ให้ผู้กล้าแชมป์ให้ทันก่อนวันนั้น

## วงจรในแต่ละวัน
1. **รับออเดอร์:** ลูกค้าสั่งอาวุธพร้อมสเปก เช่น "ดาบ เกรดแรร์ขึ้นไป คม 7+ น้ำหนักไม่เกิน 5 ภายใน 3 วัน จ่าย 120 ทอง"
2. **ซื้อวัตถุดิบ:** ราคาขึ้นลงทุกวัน บางวันกองคาราวานนำของหายากมาขาย
3. **ตีอาวุธ:** เลือก ใบมีด + ด้าม + เครื่องประดับ แล้วเล่นมินิเกมเตาหลอม (ตีกี่ครั้งขณะเหล็กยังร้อน)
4. **ส่งของ:** ได้เงิน + ชื่อเสียงตามคุณภาพและเกรด ส่งช้าหรือไม่ได้สเปก = เสียชื่อ
5. **กลางคืน ผู้กล้าออกล่า:** ผู้กล้าที่ใช้อาวุธเราออกผจญภัยจริง
   - รอด → บอกต่อ (ชื่อเสียง +) และเอาวัตถุดิบหายากมาขาย
   - ตาย → ร้านเสียชื่อ ผู้กล้ามาน้อยลง

## ⭐ เกรดอาวุธ 5 ระดับ
| เกรด | สี | ตัวคูณค่าพลัง | ตัวคูณราคา | ได้มาอย่างไร |
| :--- | :--- | :---: | :---: | :--- |
| ⚪ ธรรมดา (Common) | เทา | ×1.0 | ×1 | ตีด้วยวัตถุดิบอะไรก็ได้ |
| 🔵 แรร์ (Rare) | ฟ้า | ×1.25 | ×2 | คุณภาพการตีดี |
| 🟣 อีปิค (Epic) | ม่วง | ×1.6 | ×4 | วัตถุดิบระดับเงินขึ้นไป + ตีดีมาก |
| 🟠 ตำนาน (Legendary) | ส้ม | ×2.2 | ×10 | ต้องมีวัตถุดิบตำนานอย่างน้อย 1 ชิ้น (ได้จากผู้กล้าที่รอดกลับมาเท่านั้น) |
| 🔴 เทพนิยาย (Mythic) | แดงรุ้ง | ×3.0 | ×30 | วัตถุดิบตำนาน 3 ชิ้น + ตีสมบูรณ์แบบทุกจังหวะ + เตาระดับสูงสุด (อาวุธปราบมังกร) |

**วิธีคำนวณเกรด**
- คะแนนคุณภาพ = ระดับวัตถุดิบ + เลเวลเตา/ลูกมือ + ความแม่นในมินิเกม
- แต่ละเกรดมีเกณฑ์คะแนนขั้นต่ำ
- **เพดานตามวัตถุดิบ:** เหล็ก ได้สูงสุดแรร์, เงิน ได้สูงสุดอีปิค, มิธริล ได้สูงสุดตำนาน, ของจากมังกร/ตำนาน ถึงจะเป็นเทพนิยายได้
- **ตีวิกฤต (Critical Forge):** มีโอกาส 5% ที่เกรดจะขึ้นอีก 1 ขั้น (ไม่เกินเพดาน) เป็นจังหวะลุ้นตอนเดโม
- ออเดอร์ระบุเกรดขั้นต่ำได้ ส่วนผลการล่าของผู้กล้าใช้พลังอาวุธ = ค่าพลัง × ตัวคูณเกรด

## กลยุทธ์ (ต้องแลกอะไรทุกวัน)
- **เงินสด vs ลงทุน:** อัปเกรดเตา จ้างลูกมือ หรือซื้อแม่พิมพ์ใหม่
- **ออเดอร์ชนกัน:** วันละ 2 ชิ้น แต่ลูกค้า 4 คน: เลือกงานเงินดี งานเพิ่มชื่อเสียง หรืองานผู้กล้าที่อาจได้วัตถุดิบตำนาน
- **ข่าวสงคราม:** เช่น ออร์คบุกทางเหนือ คนต้องการขวานมากขึ้น ต้องตุนวัตถุดิบให้ถูกจังหวะ
- **ช่างคู่แข่ง:** ตัดราคา จะสู้ด้วยราคาหรือคุณภาพ
- **ซ่อมอาวุธ:** ลูกค้าเก่ากลับมาให้ซ่อม = รายได้ต่อเนื่องถ้าทำของทนทาน
- **ฉากจบวันที่ 30:** พลังป้องกันหมู่บ้าน = อาวุธที่ส่งให้ทหารรักษาเมือง + อาวุธเกรดสูงสุดที่ตีให้ผู้กล้าแชมป์
  ได้ดาวตามผล: หมู่บ้านรอด / รอดแบบเสียหาย / ล่มสลาย และโบนัสถ้าปราบมังกรด้วยอาวุธเทพนิยาย

## ระดับความยาก
ง่าย (ไว้เดโม) / ปกติ / นรกเหล็กกล้า (ราคาผันผวนแรง ลูกค้าจุกจิก มังกรแข็งขึ้น เพดานเกรดยากขึ้น)
ปรับสมดุลด้วยการจำลองเล่นหลายร้อยเกมแบบเดียวกับ หลุดมิติผี

## เกณฑ์ Rush00 ทั้ง 8 ข้อ
| เกณฑ์ | ในเกมนี้ |
| :--- | :--- |
| 1. เมนู + input | หน้าร้าน ตลาด เตาหลอม กระดานออเดอร์ คลัง |
| 2. โครงสร้างข้อมูล | list ออเดอร์ / ผู้กล้า / คลัง, dict สูตรอาวุธ / วัตถุดิบ / ลูกค้า / เกรด (เพิ่ม ดู แก้ ลบ) |
| 3. เงื่อนไข | เงินไม่พอ, วัตถุดิบไม่ครบ, เลยกำหนดส่ง, ค่าพลังหรือเกรดไม่ถึงสเปก, คลังเต็ม, ชื่อเสียงไม่พอปลดลูกค้า VIP, เพดานเกรดตามวัตถุดิบ |
| 4. ลูป | ลูปวัน ลูปเมนู ลูปผู้กล้าออกล่า |
| 5. ฟังก์ชัน | `forge(parts)`, `roll_grade(quality, cap)`, `price_today(item)`, `match_order(weapon, order)`, `hunt_result(hero, weapon)` |
| 6. อัลกอริทึม | คำนวณค่าพลังและเกรด, แนะนำสูตรกำไรสูงสุดต่อออเดอร์, คาดการณ์เงินสด, เรียงออเดอร์ตามความคุ้ม |
| 7. ตรวจ input | ตัวเลขผิด เลือกเกินช่วง ยกเลิกได้ทุกที่ ไฟล์เซฟเสีย |
| 8. ใช้งานได้จริง | เล่นครบ 30 วัน เซฟ JSON ประวัติผลเกม |
